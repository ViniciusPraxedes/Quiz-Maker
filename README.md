# Quiz Maker

A dynamic web application built with [Next.js](https://nextjs.org) for creating and taking quizzes.

## Features

- Interactive quiz interface
- Responsive design
- Built with React and Next.js App Router

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This project is configured to deploy via **Firebase App Hosting**.

1. Connect this GitHub repository to your Firebase project in the [Firebase Console](https://console.firebase.google.com/).
2. Pushing your code to the designated production branch will automatically trigger a build and deployment via Firebase App Hosting.
